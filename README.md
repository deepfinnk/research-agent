# DeepFinnk Financial Agent

This project implements an AI-powered financial agent that helps users manage their finances using their Bunq account. Users can interact with the agent through natural language queries to get financial plans and have the agent execute those plans.

## Features

*   **Natural Language Interaction:** Query the agent with financial goals or questions.
*   **Financial Planning:** Generates actionable financial plans based on user queries and Bunq data.
*   **Plan Execution:** Automatically interacts with the Bunq API (via a dedicated service) to implement the generated plan (e.g., creating budget accounts, transferring funds).
*   **Query History:** Keeps track of past interactions.

## Technology Stack

*   **Backend:** Python, Flask
*   **AI Framework:** Camel AI (specifically `camel-ai[owl]`)
*   **API Documentation:** Flasgger (Swagger UI)
*   **Dependencies:** See `pyproject.toml`
*   **Submodules:**
    *   `bunq-mcp-server`: Likely handles direct communication with the Bunq API.
    *   `owly`: Potentially shared components or utilities.

## Setup

1.  **Clone the repository:**
    ```bash
    git clone <repository-url>
    cd agent
    ```
2.  **Initialize Submodules:**
    ```bash
    git submodule update --init --recursive
    ```
3.  **Install Dependencies:**
    *   It's recommended to use a virtual environment (e.g., venv, conda).
    *   This project uses `uv` (specified in `uv.lock`) but `pip` can also be used with `requirements.txt`.
    ```bash
    # Using uv (recommended)
    uv venv
    uv sync

    # --- OR --- 

    # Using venv and pip
    python -m venv .venv
    source .venv/bin/activate # On Windows use `.venv\Scripts\activate`
    pip install -r requirements.txt 
    ```
4.  **Configure Environment Variables:**
    *   Create a `.env` file in the project root (`agent/`).
    *   Add the necessary environment variables. Based on the code, you'll likely need:
        *   `GEMINI_API_KEY`: Your API key for the underlying language model (likely Google Gemini).
        *   `BUNQ_API_URL`: The URL for the running `bunq-mcp-server` instance (e.g., `http://localhost:42069`).
        *   `FLASK_PORT` (Optional): Port for this agent service (defaults to `5001`).
    *   Example `.env`:
        ```
        GEMINI_API_KEY='your_gemini_api_key_here'
        BUNQ_API_URL='http://localhost:42069'
        FLASK_PORT=5001
        ```

## Running the Service

1.  **Ensure the `bunq-mcp-server` is running.** (Refer to its own documentation for setup/running instructions).
2.  **Start the Agent Service:**
    ```bash
    # Make sure your virtual environment is activated
    python service.py
    ```
    The service will start on `http://0.0.0.0:5001` (or the port specified in `.env`).

## API Endpoints

The service provides the following endpoints (documented with Swagger at `/apidocs`):

*   **`POST /query`**
    *   **Description:** Submit a natural language query to generate a financial plan.
    *   **Request Body:** `{ "prompt": "Your financial query..." }`
    *   **Response:** Plan generated by the DeepFinnk agent.
*   **`POST /implement-plan`**
    *   **Description:** Send a generated plan to the Bunq agent for execution.
    *   **Request Body:** `{ "plan": "The generated plan..." }`
    *   **Response:** Confirmation message and response from the Bunq agent.
*   **`GET /history`**
    *   **Description:** Retrieve the history of queries and their results.
    *   **Response:** List of past interactions.
